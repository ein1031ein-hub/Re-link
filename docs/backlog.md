## 3. 장소 추가 요청

- **학교 근처 공방·원데이클래스 1~3곳** (창작 · 에너지 보통~높음)
  - 근거: 현재 '창작' 장소는 둘리뮤지엄(관람)과 도봉동 2곳(버스 40분대)뿐. 설문 주관식 "가볍게 방문할 수 있는 공방", "1회 체험", "진입장벽 낮게" 3명
  - 필요한 정보: 이름 / 이동 시간 / 운영시간·휴무 / 1회 체험 가격 / 예약 필요 여부 / 혼자 가도 되는지
- **학교 근처 에너지 높음·사람 만남 장소** (청소년문화의집 삭제 후 0곳)
  - 지금은 '사람과 연결 + 학교 근처'를 고르면 도봉동 안내 배너가 뜸
